# Quick Start - DocTrack

## Running the Application

```bash
python manage.py runserver
```

Then open: http://localhost:8000

## Features Ready to Use

✅ Document upload  
✅ Secure sharing with password protection  
✅ Document expiry dates  
✅ View tracking (views, unique IPs, time spent)  
✅ Analytics dashboard  
✅ Platform detection  

## Next Steps

1. Create a superuser to access the admin panel:
```bash
python manage.py createsuperuser
```

2. Access admin at: http://localhost:8000/admin

3. Deploy to production using Render, Railway, or Fly.io (see README.md)
